# Third-party notices

## Nuclear Option

Nuclear Option, the original A-19 Brawler and T/A-30 Compass aircraft designs, meshes, textures, audio, shaders and game code belong to **Shockfront Studios** and their respective rights holders.

This unofficial plugin clones and adapts the installed game's aircraft objects at runtime. No extracted game meshes, textures, audio, managed assemblies, asset bundles or editable game-model files are included in the repository or release. The preview renders depict the installed game's aircraft with the mod's custom exhaust geometry; they are illustrative renders, not a licence to reuse game assets.

The original mod source and custom procedural exhaust geometry are distinct from those existing game assets. The repository's MIT licence applies only to original mod content.

[Official game page](https://store.steampowered.com/app/2168680/Nuclear_Option/)

## NOMNOM permission clarification

The plugin clones objects from the user's installed game at runtime; the repository previews are renders of that derived aircraft. No raw game meshes, textures, sounds, assemblies or asset bundles are distributed. On 8 November 2026, a [NOMNOM maintainer answered that additional permission was not required for the approach described](https://github.com/KopterBuzz/NOMNOM/pull/500#issuecomment-6716029120), and the registry submission was merged. This records the registry maintainer's clarification; it does not claim a separate licence or endorsement from Shockfront Studios.
